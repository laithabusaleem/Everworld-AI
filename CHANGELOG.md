# Changelog

- Framework-independent TypeScript simulation engine
- Rule-based world generation and character decisions
- Optional OpenAI-compatible LLM provider with validation + fallback
- Express API with SQLite persistence and migrations
- React UI: map, inspector, feed, timeline controls, create/preview flow
- Experimental Worlds scenario comparison
- Automated engine and API tests
- GitHub Actions CI
- Product documentation and coastal village example
